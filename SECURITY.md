# Security Policy

## Supported versions

Only the latest release of `dibs` receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub Security Advisories:
<https://github.com/vivekyarra/dibs/security/advisories/new>

Include:

- the affected version (`dibs --version`) and OS/arch,
- steps to reproduce or a proof of concept,
- the impact you expect (for example: a guard rule bypass, credential exposure, or command injection via ticket content).

You should get an acknowledgement within 3 business days. Once a fix is ready we will publish a release and an advisory, and credit you unless you prefer otherwise.
